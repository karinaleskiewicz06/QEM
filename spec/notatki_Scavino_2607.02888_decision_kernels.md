## 1. Główna teza
Dokładność QEM (MSE w przestrzeni R^n) i niezawodność decyzji opierających się na wartościach oczekiwanych (argmin, ranking, top-k, akceptacja kroku, etykieta fazy) to różne obiekty. Decyzje niezmiennicze względem przesunięcia zależą tylko od różnic wartości (gapów). Minimalnym obiektem kompletnym dla takich decyzji jest **prawo rozkładu residualnych gapów** 𝓛(L E_m). W reżimie gaussowskim streszcza je para (efektywny margines, jądro decyzyjne) = (µ_m, Σ_m) = (Δ + L a_m, L K_m Lᵀ). Σ_m nie jest dowolną macierzą PSD: to pullback współdzielonego szumu urządzenia przez mapę mitygacji.

## 2. Formalizm (Sec. 3–4)
- Krajobraz X={x_0..x_{n-1}}, idealny F, unikalne minimum x_0 (Ass. 3.1), marginesy Δ_i=F(x_i)−F(x_0)>0 (eq. 6).
- Estymator F̂_m = F + E_m, E_m = a_m + ξ_m (eq. 7–8). a_m to obciążenie niezależne od budżetu, K_m^(B) to kowariancja przy budżecie B, K^unit = B·K^(B) (eq. 9). MSE_m = (‖a_m‖² + tr K_m)/n (eq. 1, 10).
- Operator gapów (Lv)_i = v_i − v_0 (eq. 11), Δ̂ = Δ + L a_m + L ξ_m (eq. 12). Efektywny margines µ_m = Δ + L a_m, jądro decyzyjne Σ_m = L K_m Lᵀ (eq. 13; per-unit eq. 14–15). Ryzyko R_m(B) = P[∃i: µ_{m,i} + (Lξ)_i ≤ 0] (eq. 17).
- **Iloraz decyzyjny** Q = Rⁿ/span{1} (Def. 3.2, eq. 18).
- **Tw. 3.3 (faktoryzacja ilorazowa).** Każda mierzalna skończona decyzja δ niezmiennicza względem v→v+c1 faktoryzuje się jako δ = δ̃∘π = δ̄∘L (eq. 19–21). Rozkład L E_m razem z L F jest więc kompletny dla decyzji, a rozkład E_m w Rⁿ niesie informację „cechowania” bez znaczenia dla decyzji.
- **Prop. 3.4 (niezmienniczość cechowania).** E′ = E + c1 daje L E′ = L E, więc ryzyka wszystkich decyzji rankingowych/argmin/top-k są identyczne. MSE można przy tym dowolnie powiększyć (eq. 22–24).
- **Def. 4.1 (skończona decyzja na gapach).** Wymaga kontrastu L_D z L_D 1 = 0, marginesu b_D i zbioru sukcesu S; ryzyko R = P[b_D + L_D E ∉ S] (eq. 25–26). Obciążenie wchodzi do µ, nie do b_D (eq. 27).
- **Tw. 4.2 (dostateczność i minimalność prawa gapów).** (a) Ryzyko zależy tylko od 𝓛(U_m), U_m = L_D E_m. (b) Równość praw ⇔ równe ryzyka dla wszystkich decyzji borelowskich. (c) Dla argmin wystarcza rodzina przesuniętych ortantów (eq. 29–30). (d) Wystarczają wszystkie półprzestrzenie hᵀL_D E ≤ t (eq. 31), z twierdzenia Craméra–Wolda.
- **Tw. 4.5 (forma iff/Blackwella).** Reprezentacja T jest dokładnie spójna decyzyjnie ⇔ prawo gapów da się z niej odtworzyć (eq. 34–35). Prawo gapów jest najgrubszą bezstratną reprezentacją. Dominacja Blackwella zachodzi przez jądro Markowa na gapach (eq. 38).
- **Prop. 4.6 (gaussowski garbling).** Σ_B − Σ_A ⪰ 0 ⇒ A Blackwell-dominuje B (eq. 40–45); wystarczy dodać szum N(0, Σ_B−Σ_A). Remark 4.7: dla pełnej rodziny przesunięć warunek Loewnera jest też konieczny.

## 3. No-go dla benchmarków marginalnych (Sec. 5)
- **Tw. 5.2.** (a) Istnieją dwa centrowane pola gaussowskie o identycznych marginesach punktowych, wariancjach, CI i MSE, ale o różnym ryzyku argmin. Dowód: K_A = σ²I, K_B = σ²[[1,ρ],[ρ,1]], Var gapu 2σ² vs 2(1−ρ)σ² (eq. 52–56). Każdy losowy selektor marginalny myli się z prawd. ≥1/2 na jednej z dwóch etykietowań. (b) Może być MSE_A < MSE_B przy R_A > R_B (wystarczy dodać do B szum wspólny C1). (c) Wykładniki I_A = Δ²/(4σ²) < I_B = Δ²/(4(1−ρ)σ²) (eq. 57). Metoda wybrana przez MSE może więc być wykładniczo gorsza: lim (1/B) log(R_A/R_B) = I_B − I_A > 0 (eq. 51).
- Diagonala K nie wystarcza: Σ(i,j) = K(i,j) − K(i,0) − K(0,j) + K(0,0) (eq. 58). Paper podaje trzy „świadki ostrości”: inflację wspólną; te same marginesy przy innym Var(E_i − E_j); te same jednowymiarowe gapy przy innych korelacjach.
- **Prop. 5.3.** No-go jest realizowalny przez liniowe pullbacki z tej samej C_dev = diag(σ²,σ²,q²,ε²) (eq. 59–65).
- Przykład wstępny (Sec. 1): K_A = 0.40·11ᵀ + 0.01 I₃ i K_B = 0.08 I₃ dają MSE_A = 0.41 i MSE_B = 0.08, ale ryzyka argmin p_A = 1.54×10⁻¹² i p_B = 1.17×10⁻². Metoda o niższym MSE jest więc gorsza o wiele rzędów wielkości.

## 4. Pullback QEM (Sec. 6) i formuły gaussowskie (Sec. 7)
- **Tw. 6.1 (restrykcja pullbacku).** Dla liniowego F̂ = M_m Y: K_m = M_m C_dev M_mᵀ i Σ_m = (L M_m) C_dev (L M_m)ᵀ (eq. 72) dokładnie. Dla procedur gładkich (metoda delta, Jakobian J_m) równości zachodzą do o(B⁻¹) (eq. 69–70, 73). Wnioski: rank Σ_m ≤ rank C_dev (eq. 75); vᵀΣv = 0 ⇔ C_dev^{1/2} M_mᵀ Lᵀ v = 0 (eq. 76). Dla mapy dopasowanej z danych (CDR) wynik jest warunkowy względem dopasowania albo wymaga dołączenia danych treningowych do Y.
- **Sec. 6.2 / Prop. 6.2.** Dla obserwabli Pauliego Var(Y) = (1−f²)/B (eq. 79–80); C_dev ≈ D_shot + J_p V_p J_pᵀ (eq. 83, 85). Dryf kalibracji o wariancji O(1) nie skaluje się z B. Daje on podłogę ryzyka i nie wchodzi do wykładnika. Dla globalnej depolaryzacji f = α_s(p) F (eq. 84) niepewność p daje korelacje ∝ F(x_i)F(x_j).
- **Prop. 7.1 (CLT gapów).** √B L ξ → N(0, Σ_m) (eq. 92); Berry–Esseen O(B^{-1/2}) dla zdarzeń wielościennych.
- **Prop. 7.2 (dokładne ryzyko gaussowskie).** R_m(B) = 1 − Φ_d(√B µ_m; Σ_m) (eq. 95); równoważnie P[max_i(−Z_i/µ_i) ≥ √B] (eq. 96).
- **Tw. 7.4.** Wykładnik I = inf ½ yᵀΣ†y po obszarze porażki (eq. 99–105). Dla argmin I_m = min_i µ_i²/(2Σ_ii) (eq. 106). Lemat B.1 podaje warunek regularności.
- **Tw. 7.5 (klasyfikacja diagonalna/pozadiagonalna).** Ściana aktywna daje I_S = ½ c_Sᵀ(H_S Σ H_Sᵀ)⁻¹ c_S (eq. 109), a dla selektora współrzędnych ½ µ_Sᵀ Σ_SS⁻¹ µ_S (eq. 110). Prosty argmin ma wykładnik diagonalny. Ranking, top-k i zdarzenia koniunkcyjne zależą od korelacji pozadiagonalnych. Cor. 7.6: prefaktor B^{-|S|/2}. Prop. 7.8: pierwszorzędowe porównanie przez gradient G = ∇_Σ R; ranking jest stabilny, gdy |⟨G_A,E_A⟩ − ⟨G_B,E_B⟩| ≤ ρ|Δ_AB|, przy ρ = 0.25 użytym w hardware.

## 5. Sygnatury metod (Sec. 8)
- **ZNE (Tw. 8.1).** a = Σ c_ℓ b_ℓ, Σ_ZNE = Σ_ℓ c_ℓ²/w_ℓ Σ_ℓ (eq. 128); przy równym podziale Σ_ZNE = q‖c‖² Σ_0 (eq. 129). **Cor. 8.3:** ZNE poprawia decyzję (jedna aktywna luka) ⇔ µ_ZNE²/Σ_ZNE > µ_Raw²/Σ_Raw (eq. 131). Region separacji: MSE_ZNE < MSE_Raw przy odwrotnej nierówności (eq. 132). **Tw. 8.4:** współczynniki ZNE optymalne decyzyjnie przy certyfikowanych marginesach dają SOCP: min max_i cᵀQ_i c/µ_i² przy Ac = ρ_R (eq. 136–137). Wspólne projektowanie współczynników i alokacji strzałów jest wypukłe (App. B, eq. 192–193).
- **CDR (Tw. 8.5).** Σ_CDR,θ(i,j) = (φ_i−φ_0)ᵀ V_θ (φ_j−φ_0) (eq. 144–146). Niepewność treningu może być duża punktowo i mała w przestrzeni decyzji, gdy φ_i ≈ φ_0. Warunek niewidzialności definiuje eq. 147, a obciążenie transferowe κ-kontrolowane eq. 148.
- **PEC (Tw. 8.7).** µ = Δ, Σ = Γ²·Σ_ideal, I_PEC = Γ⁻² I_unbiased (eq. 151–152). PEC wygrywa z CDR ⇔ Δ²/(Γ²Σ_id) > (Δ+δ_CDR)²/Σ_CDR (eq. 158, rys. 4). Wykładnik zależy od znaku: I = 0 dla µ ≤ 0 (eq. 154).
- **Prop. G.1.** Zniekształcenie dodatnio-afiniczne αF + c (α > 0) zachowuje każdy ranking, argmin i top-k.

## 6. Twierdzenie odwrotne na poziomie strzałów (Sec. 9)
- **Tw. 9.1.** Przy stałej, nieadaptacyjnej alokacji B_s każda reguła spełnia sup max{P_ν[δ≠0], P_θ′[δ=0]} ≥ ¼ exp[−min_i inf KL(P_ν^(B) ‖ P_θ′^(B))] (eq. 162). Wykładnik nie może przekroczyć I*_shot(w) = min_i inf Σ_s w_s KL(p_{s,ν}‖p_{s,θ′}) (eq. 163). Dowód: Bretagnolle–Huber.
- **Cor. 9.2–9.3.** W lokalnym modelu gaussowskim z równą kowariancją barierą jest I*_argmin = min_i µ_i²/(2Σ_ii) (eq. 168), a reguła plug-in ją osiąga (eq. 170). To wynik lokalnie minimaksowy, nie punktowy. Cor. C.1: Σ_eff = G I(w,θ)† Gᵀ (eq. 200). Gdy estymator QEM ma Σ ⪰ Σ_eff (np. przez sztywne momenty Richardsona), powstaje „strata efektywności decyzyjnej”.

## 7. Diagnostyki i reguła wyboru (Sec. 10)
- Pasmo krytyczne C_τ = {i: 0 < Δ_i ≤ τ} (eq. 173). Należy je ustalić z pilota, z modelu bezszumowego albo przez podział próby, nie z danych raportowych.
- DRI^unit_m(C) = min_{i∈C} µ_{m,i}/√Σ_m(i,i) (eq. 175); DRI(B) = √B·DRI^unit (eq. 176); ½DRI² to wykładnik (eq. 177). GRI_m(B,C) = P[∃i∈C: µ_i + B^{-1/2}Z_i ≤ 0] (eq. 178). GVS = tr(L_C K L_Cᵀ)/(tr K_C + ε₀) (eq. 179) jest tylko diagnostyką.
- **Algorytm 1 (wybór decyzyjny):** dla m ∈ {Raw, ZNE, CDR, PEC} policz µ̂_m = L(f̂ + â_m) i Σ̂_m = L K̂_m Lᵀ, następnie R̂_m(B) z Prop. 7.2, wybierz m* = argmin R̂_m i zwróć ryzyko wraz z diagnostyką stabilności (App. A: Tw. A.1–A.3, eq. 182–189).
- Sec. 11.2: MSE wystarcza m.in. dla **decyzji binarnych ze znaną rodziną kowariancji**, gdy MSE wyznacza wariancję gapu lub margines. Wystarcza też przy niezależnym homoskedastycznym szumie, przy identycznej strukturze korelacji i przy dużych marginesach.

## 10. Ograniczenia (Sec. 13 i własne)
Autor wymienia: brak konwersji kwantowo-fisherowskiej niezależnej od pomiaru, brak alokacji adaptacyjnej, brak konwersji dla złożonych zdarzeń top-k i rankingu. Do tego wszystkie wyniki P1–P5 pochodzą z symulacji QAOA-MaxCut, głównie przy szumie zachowującym ranking. Hardware to jedna mikro-komórka, która nie przeszła kryterium kierunkowego. Efekty praktyczne są poniżej progu 0.15. Mosty CLT/LDP są asymptotyczne (brak stałych Berry–Esseena dla shot→Gauss). CDR jest „płaski decyzyjnie” w sensie trywialnym, bo dopasowanie było dodatnio-afiniczne. Praca jest jednoautorska, bez recenzji.

## 11. Przełożenie na nasz projekt (klasyfikator, decyzja sign⟨O⟩) — analiza własna
1. **Nasza decyzja nie jest niezmiennicza względem przesunięcia.** ŷ(x) = sign⟨O⟩_x ma próg w zerze, czyli kontrast L_D = e_xᵀ z L_D1 ≠ 0, i nie spełnia Def. 4.1 ani Tw. 3.3. Offset wspólny *zmienia* nasze decyzje. Zachowuje je tylko skalowanie dodatnie (szczególny przypadek Prop. G.1 przy c = 0). Dla każdej próbki x jądro decyzyjne jest 1×1, a jego rolę pełni wariancja punktowa. Margines efektywny to **µ_m(x) = s(x)·(F(x) + a_m(x))**, gdzie s(x) = sign F_noiseless(x), bo metryką jest zgodność z modelem bezszumowym. Wynika to z naszego zapisu w pamięci projektu. Ryzyko per próbka: R_m(x) = Φ(−µ̂_m(x)/σ̂_m(x)) (Prop. 7.2 dla d = 1). Oczekiwany odsetek niezgodności to D_m = (1/N)Σ_x R_m(x). Dla wartości oczekiwanej wystarczają marginesy, ale dla rozkładu liczby niezgodności i porównań sparowanych potrzebna jest pełna kowariancja N×N między próbkami. Wnoszą do niej wspólny dryf kalibracji oraz wspólne (â, b̂) w CDR.
2. **Pomiary per metoda (z naszych danych).**
   - Raw: µ = s·Ō, σ² = Var_shot(mean-Z)/B, z bootstrapu strzałów (5 Z są skorelowane).
   - ZNE: µ = s·Σc_ℓŌ_ℓ, σ² = Σc_ℓ²σ_ℓ² (Tw. 8.1).
   - CDR: µ = s(âŌ + b̂), σ² = â²σ_Ō² + (Ō,1)V_θ(Ō,1)ᵀ (Tw. 8.5; V_θ z bootstrapu 10 obwodów treningowych).
   - CDR+twirl: to samo dla ramienia twirlowanego oraz dla kontroli M = 6 kopii przy równym budżecie.

   Kalibrację sprawdzamy jak w P3: GRI vs empiryczna niezgodność, z tolerancją 0.05. Pasmo krytyczne |F_noiseless(x)| ≤ τ ustalamy z symulatora z góry.
3. **Przewidywania wyprowadzone (nie z pracy).** (a) CDR zmienia decyzję tylko przez próg t̂ = −b̂/â: przy â > 0 decyzje CDR różnią się od Raw tylko dla próbek z Ō między 0 a t̂. Jeśli b̂ ≈ 0, CDR jest decyzyjnie płaski, mimo że poprawia MSE. Wspólne t̂ koreluje błędy wszystkich próbek. (b) W modelu czystej globalnej depolaryzacji (⟨O⟩(λ) = α^λF) Raw ma poprawny znak, a ZNE przy równym budżecie *nie może* poprawić wykładnika decyzji. Wzmocnienie marginesu wynosi maksymalnie 1.5 / 1.875 / 2.1875 dla węzłów {1,3}/{1,3,5}/{1,3,5,7}. Z kolei wzmocnienie odchylenia standardowego wynosi √(q‖c‖²) = 2.236 / 3.957 / 6.75 (policzone przez nas).
